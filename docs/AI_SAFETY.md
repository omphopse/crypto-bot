# AI Safety & Autonomous Agent Safeguards

## 1. Zero Direct Order Authority
The AI autonomous decision engine and research layer possess **zero direct order placement capability**.
- All trade intents generated by the autonomous agent must pass through the deterministic, rule-based `RiskEngine`.
- The `RiskEngine` is the sole authoritative gatekeeper enforcing balance, position limits, drawdown caps, and emergency stops.

## 2. Information-Only Research Boundary
- External web content is strictly classified as **Untrusted External Data**.
- Web text is never injected into system prompts or developer instructions.
- External documents cannot trigger tool calls or alter agent execution parameters.

## 3. Strict Live Trading Disablement
- `LIVE_TRADING_DISABLED` is enforced across all API endpoints, broker adapters, and state machines.
- `AutonomousMode.LIVE_LOCKED` throws an immediate exception and halts session start.
- Broker connectivity is restricted exclusively to Alpaca Paper and Bybit Demo.

## 4. Prompt Injection Defense
- Multi-vector detection of instruction override patterns (`PromptInjectionDetector`).
- Layered defenses:
  1. Content sanitization (HTML and script tag stripping).
  2. Pattern analysis (`CLEAN`, `SUSPICIOUS`, `BLOCKED`).
  3. Structured evidence extraction preserving provenance without execution authority.
